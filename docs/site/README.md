# Landing page

`site/index.html` is the published page (https://krimvp.github.io/sous/, published with `scripts/publish-site.sh`).
It was made by an art director, a copywriter, a builder and reviewers working from these files:

- [ART.md](ART.md): the visual spec and the review checklist.
- [COPY.md](COPY.md): the page text, with fact sources. Every claim was fact-checked against the code.
- [REVIEW-5.md](REVIEW-5.md): the last art review, with polish left for later.

To iterate: change the spec or copy here, rebuild the page against them, review with screenshots, then fact-check the copy.
