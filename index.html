Install

$ npm install -g @krimvp/sous

Needs Node 22.19 or later, git, and at least one agent CLI you are logged into: Claude Code, Codex or Pi. Leads use your Pi login (Ollama Cloud or ChatGPT). Run sous inside the git repository the agents should work in.

The brigade

You
Call the order: a goal, or a fixed menu of steps in a file. Answer questions, approve plates, send things back.
Sous
A lead agent splits the order across stations. Stations can be leads too, as many levels deep as you allow.
Cooks
Claude Code, Codex or Pi do the work, each at its own station: a git worktree on its own branch.
The pass
Every plate is merged one at a time and checked on the merged result. A clash goes to an agent who fixes it.
Service
The finished order is on branch sous/<run>. If the kitchen stops, sous resume picks up where it was.
