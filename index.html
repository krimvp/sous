      How a big order is split

      A lead can hand a part to a sub-lead with its own cooks and checks. Leads nest 3 deep by default, up to 8 with --max-depth.

      Get started

      Node 22.19+, git, and Claude Code, Codex or Pi logged in. Leads use your Pi login.

      $
      npm install -g @krimvp/sous

      Install the CLI (coming to npm).

      $
      sous run "goal"

      Start a run inside your git repository.

      $
      sous status

      See the tree and what waits for you.

      • Your agents--agents agents.json: your own agents, with model and instructions.
      • Steeringsous approve, answer, cancel: approve gates, reply, cancel subtrees.
      • Crash recoverysous resume continues after a crash without repeating finished turns.
      • MergingMerges go one at a time; conflicts go to an integrator agent.
      • TracesExports ATIF and Langfuse traces.
      • PermissionsNo sandbox: workers have full permissions.
