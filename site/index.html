Murmuration

Give it a goal. A tree of agents builds it, merges it and checks it.

$ murm run "Add a --precision option to the CLI, with tests"

Install

$ npm install -g @krimvp/murmuration

Needs Node 22.19 or later, git, and at least one agent CLI you are logged into: Claude Code, Codex or Pi. Lead agents use your Pi login (Ollama Cloud or ChatGPT). Run murm inside the git repository the agents should work in.

How it works

  • A lead agent splits your goal into children: workers, checks, approval gates, or sub-leads that split further.
  • Workers run on Claude Code, Codex or Pi, each in its own git worktree.
  • Finished work is merged one branch at a time and checked on the merged result. A merge conflict goes to an agent that resolves it.
  • Plain code runs all of it and records every step, so a stopped run resumes where it left off.
  • The result lands on branch murm/<run>. Your own branch is untouched until you merge it.
