Murmuration

Give it a goal. A tree of agents builds it, merges it and checks it.

$ murm run "Add a --precision option to the CLI, with tests"
  • Lead agents split the goal into work.
  • Claude Code, Codex and Pi do it, each in its own git worktree.
  • Every branch is merged and checked; conflicts go to an agent.
  • It runs on your machine and resumes after a crash.
